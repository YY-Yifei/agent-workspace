# 每个程序一个智能体

这一版把「一个全局 agent」换成了「每个程序一个」。它不是实现细节，是**产品形态**：
用户打开的是「番茄钟」，那就应该有一个懂番茄钟的助手，而不是一个懂怎么造程序、
顺带也能聊番茄钟的万能助手。

## 三句话说清

1. **内核只内置一个程序：小助理**（`agentworkspace/assistant.py`，pid=`assistant`）。
   它手上有「手」（读/写/搜/跑命令）和「造程序」（`plugin_write` 等）。
2. **每个程序一条 aaas 会话**（`agentworkspace/link.py` 的 `Link` + `Hub`），用到才连。
   它的 instructions 只讲它自己，它的能力面只有它自己。
3. **隔离只写一处**：`Runtime.capabilities_of(pid)`。别处不许再按 pid 过滤。

## 隔离长什么样

| 程序 | 声明出去的能力 | 它的指令讲什么 |
|---|---|---|
| 小助理 | `assistant_tree/read/write/search/shell/plugin_*/plugin_call` | 怎么造程序、程序契约 |
| 番茄钟 | `pomodoro_start/status/stop/history` | 只有这 4 件 |
| 心情日记 | `mood_add/recent/stats/remove/undo` | 只有这 5 件 |

真跑出来的两句话（不是设计稿）：

- 问 `心情日记` 的助手「你能帮我再做一个新程序吗？比如记账」→
  「做新程序这个我做不到，我只能记、看、删心情日记；要加记账功能得找小助理。」
- 小助理造完 `mood` 之后，用 `plugin_call` 把 `add/recent/stats/remove/undo`
  逐个跑了一遍（同一条 dispatch，和人点按钮完全一样）。

## 界面形态只有两种

```
小助理（uiKind=none）        有页面的程序（web / native）
┌────┬──────────────────┐   ┌────┬───────────────┬──────────┐
│窄栏│   对话面板        │   │窄栏│  程序页面      │ 对话面板  │
└────┴──────────────────┘   └────┴───────────────┴──────────┘
```

- 窄栏 56px，只有图标（emoji）+ 悬停标题。没有文件树、没有「N 个能力」、没有术语。
- 程序的对话面板**不是可选件**：每个程序至少一张嘴。
- 没有页面的程序就只有对话 —— 它不是残缺，它就是「只会说话的程序」。

## 三个踩过的坑（都会静默失败）

**1. `instructions` 有 4096 字符硬上限。**
实测 4000 可以、4096 就 `PARAMS_INVALID`（轮在 2ms 内失败，界面看起来就是「没人理」）。
所以 `link.clip_instructions()` 截到 4000 并留痕（事件 + 截断标记），
`selftest` 里断言每份组装后的提示词都不超限。

**2. 页面订阅事件会形成「刷新回环」。**
页面写 `if (ev.type === 'call.ok') refresh()`，而它自己的 `refresh()` 就是两次 call，
每次又发一个 `call.ok` —— 自己触发自己。轮次里页面已订阅，回环启动，请求被挤出失败，
用户看到一条红条 `Failed to fetch`，而数据其实是对的。
规矩：**只对 `ev.source === 'agent'` 刷新**（别人的动作），自己的读写自己渲染。

**3. 首句会丢。**
程序第一次被打开时连接才建起来（connecting），而那恰好是用户最可能立刻开口的时刻。
原来的实现直接回「还没连上」—— 那句话就消失了。现在 `Link.send` 等最多 20 秒。

## 验收方式（不靠感觉）

```bash
python -m agentworkspace.selftest          # 55 项：schema / 隔离 / 提示词长度 / 窗口适配 / 闸门
python -m agentworkspace.qa                # 真桌面：外壳渲染 / 两种界面形态 / 原生窗口
python -m agentworkspace.qa ui --with-chat # 截图前真说一句，且确认截到的窗口就是它自己
```

`qa` 的三条硬规矩（都是踩出来的）：

- 截图前把窗口置前，并**确认前台确实是目标窗口**，否则这张图就是别人的画面；
- 进程要 DPI 感知：`GetWindowRect` 给逻辑坐标、`ImageGrab` 按物理像素裁，不统一会整体偏移；
- 窗口必须装进工作区（`shell.fit`）：1440×900 的桌面上开 1180×800 在 (123,123)，
  底边 923 已经掉到屏幕外 —— 输入条永远看不见。
